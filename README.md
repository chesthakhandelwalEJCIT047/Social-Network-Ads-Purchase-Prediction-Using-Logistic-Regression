# Social Network Ads – Purchase Prediction Using Logistic Regression

## Introduction

This project demonstrates the implementation of **Logistic Regression**, a supervised machine learning algorithm, to predict whether a user is likely to purchase a product based on their **age**.

The project uses the **Social Network Ads dataset**, which contains information about users and their purchasing decisions. During the data preprocessing stage, unnecessary columns such as `User ID`, `Gender`, and `Salary` are removed to focus the model on the **Age** feature.

A scatter plot is used to visualize the relationship between **Age** and the purchasing decision. The dataset is then divided into training and testing sets, after which a **Logistic Regression model** is trained and evaluated.

The project also demonstrates how a trained model can be used to predict the purchasing decision for a new user.

### Objective

The main objective of this project is to:

* Understand the concept of **Logistic Regression**
* Perform basic data preprocessing
* Visualize the relationship between age and purchase decisions
* Split the dataset into training and testing data
* Train a Logistic Regression model
* Evaluate the model's performance
* Make predictions on new data

This project is a simple practical implementation of a **binary classification problem**, where the output represents whether a user purchases the product (`1`) or does not purchase it (`0`).
